# Ferramenta de uso pessoal para treinamento de LLM

- Este repositório é destinado à divulgação de ferramentas produzidas durante um projeto pessoal, seguem informações:

## Yolo Labeller 

  Este progama em especial é destinado à denominação de multiplas imagens simultaneamente, gerando classe, id e coordenadas dentro da imagem
- Basta selecionar as imagens desejadas, definir a classe e id desejados e desenhar um quadrado em volta do objeto

- Todos os arquivos txt obtidos podem ser baixados simultaneamente em "Baixar todas as anotações"

- Este programa foi desenvolvido tendo em vista a utilização da biblioteca Ultralytics, mantenha em mente que a arquitetura pode variar conforme aplicação!


## Nammer

Auto explicativo, criei este programa apenas para facilitar a nomeação em massa de arquivos de imagem
- Selecione o diretório desejado e apenas digite o prefixo padrão, todos os arquivos serão renomeados automaticamente em ordem numérica


## Considerações

- Até o atual momento este diretório apresenta apenas algumas ferramentas simples, porém pretendo expandi-lo futuramente quando houver necessidade real de maior organização

- Considerando a natureza simples de tais programas (traduzindo de forma simples eu passei tempo demais nelas e não quero duplicar o trabalho comentando) não foi necessário comentar ou documentar o processo, futuras atualizações possivelmente trarão estrutura mais organizada (quando der vontade eu faço)

- Estas ferramentas são de uso livre, não pretendo impedir qualquer um de recorrer a elas ao invés de perder tempo por nada
